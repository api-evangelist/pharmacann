# PharmaCann

> PharmaCann is one of the largest vertically integrated cannabis companies in the United States,
> founded in 2014. It operates nine cultivation and processing facilities and retail dispensaries
> across eight states under two retail banners, LivWell and Verilife. PharmaCann publishes no
> public API, no developer program and no machine-readable API contract.

## What this file is

This llms.txt was GENERATED by API Evangelist from the public PharmaCann corporate site and this
repository's own artifacts. It is NOT published by PharmaCann. PharmaCann serves no /llms.txt on
any of its hosts (www.pharmacann.com, www.verilife.com, www.livwell.com all return 404).

Note for crawlers: PharmaCann's own robots.txt at https://www.pharmacann.com/robots.txt names a
long list of AI user-agents (GPTBot, ClaudeBot, anthropic-ai, Google-Extended, CCBot, Bytespider,
Meta-ExternalAgent, Applebot-Extended and others). Honor it.

## API surface

- No public REST, GraphQL, gRPC, SOAP or event API was found on any PharmaCann-owned host.
- No OpenAPI, Swagger, AsyncAPI, GraphQL SDL, .proto or WSDL is published.
- No MCP server and no A2A agent card are served.
- No developer portal, API reference, sandbox, SDK, CLI or Postman collection exists.
- Retail ordering on the Verilife and LivWell storefronts is a consumer web experience; any
  underlying menu/ordering API belongs to the third-party dispensary-commerce platform behind it,
  not to PharmaCann, and is therefore not catalogued here.
